LoanLens

Upload a loan application PDF and run the full LoanLens analysis pipeline. The LLM extracts applicant fields from the document, while deterministic Python rules calculate EMI, FOIR, risk flags, and the final lending decision. Low-confidence extractions are routed to human review — the model reads, the rules decide.

Pipeline
PDF → Text Extraction → LLM Extraction → Confidence Check → Rules Engine → Decision Router → Database → JSON Response
